# Доступность текста

## Общие принципы

- Пишите так, чтобы содержание было понятно читателям с разным уровнем подготовки.
- Используйте ясные формулировки и раскрывайте специальные термины при первом упоминании: сначала укажите термин, затем кратко объясните его значение. Например: «Контрастность — это степень различимости текста и фона».
- Не передавайте информацию исключительно через цвет, положение элемента или визуальное оформление.
- Для важных предупреждений, ограничений и условий используйте текстовые пояснения.
- Предпочитайте короткие предложения и делите сложную информацию на смысловые блоки.

## Заголовки и структура

- Соблюдайте логическую иерархию заголовков.
- Не пропускайте уровни заголовков без необходимости.
- Используйте заголовки, которые отражают содержание соответствующего раздела.
- Разделяйте длинные тексты на смысловые блоки.
- Используйте списки для перечисления однородных элементов или последовательности действий.
- Не используйте заголовки только ради визуального выделения текста.

## Ссылки

- Используйте осмысленный текст ссылки, который понятен даже при чтении вне контекста абзаца и описывает назначение или содержание целевой страницы.
- Избегайте формулировок «нажмите здесь», «по ссылке» и общих названий вроде «Документация».
- Указывайте назначение ссылки конкретно. Например, вместо «Документация» используйте «Документация по настройке проекта», если ссылка ведёт на соответствующий материал.
- Проверяйте, что текст ссылки позволяет понять, куда она ведёт, без необходимости читать окружающий абзац.

## Изображения и диаграммы

- Добавляйте альтернативный текст к изображениям, которые передают полезную информацию.
- Описывайте назначение схемы или диаграммы в основном тексте.
- Для сложных диаграмм приводите текстовое объяснение ключевых элементов и связей.
- Для чисто декоративных изображений не добавляйте описание, которое отвлекает от содержания.
- Не размещайте важные пояснения только внутри изображения, если их можно продублировать текстом.

## Таблицы и списки

- Используйте таблицы для сопоставления однотипных данных, а не для визуального размещения текста.
- Задавайте понятные заголовки столбцов.
- Не используйте таблицы, если информацию проще представить списком.
- Формулируйте пункты списков так, чтобы их смысл был понятен без опоры на оформление.
- Не объединяйте ячейки без необходимости, если это затрудняет понимание структуры таблицы.

## Контрастность и визуальное оформление

- Обеспечивайте достаточную контрастность текста и фона, чтобы текст оставался различимым.
- Для обычного текста ориентируйтесь на минимальное соотношение контрастности 4,5:1.
- Для крупного текста ориентируйтесь на минимальное соотношение контрастности 3:1.
- Не используйте цвет как единственный способ обозначения ошибки, предупреждения или состояния.
- Проверяйте контрастность с помощью инструмента проверки цветового контраста.

## Код и технические примеры

- Не используйте только цвет для различения элементов кода или результатов.
- Сопровождайте сложные примеры пояснениями об их назначении и ожидаемом результате.
- Если изображение содержит важный фрагмент кода, по возможности приводите этот код в текстовом виде.
- Используйте форматирование кода так, чтобы команды, имена файлов и идентификаторы можно было легко различить в тексте.
- Не полагайтесь только на визуальное выделение при объяснении различий между примерами.

## Проверка доступности

Перед публикацией документа проверьте:

- [ ] Заголовки отражают структуру и содержание документа.
- [ ] Специальные термины объяснены при первом упоминании.
- [ ] Ссылки понятны вне контекста окружающего абзаца.
- [ ] Информативные изображения имеют альтернативный текст.
- [ ] Назначение сложных диаграмм объяснено текстом.
- [ ] Важные сведения не передаются только цветом или визуальным оформлением.
- [ ] Контрастность обычного текста и фона составляет не менее 4,5:1.
- [ ] Контрастность крупного текста и фона составляет не менее 3:1.
- [ ] Таблицы имеют понятные заголовки и используются по назначению.
- [ ] Списки помогают воспринимать информацию, а не заменяют необходимое объяснение.
- [ ] Текст не содержит необъяснённых специальных терминов.
- [ ] Сложные технические примеры сопровождаются пояснениями.
